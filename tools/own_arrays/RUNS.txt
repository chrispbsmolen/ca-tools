Runs behind the 24 arrays of this folder (2026-10-27)

All runs were made in a Linux x86_64 cloud workspace on 2026-10-27, with the
scripts of this folder (compiled with gcc -O2). File names are those of the
working folder; the stored arrays are in ../../table/arrays/ under
CA_N_t_k_v_<first 8 hex digits of the sha256>.txt.

Programs named in the commands:
  nck       nck_early.c, the first version of nck.c (used for the runs
            without SHAKE=); nck.c replaced its enumeration code and added
            the SHAKE random walk, so the two do not give the same runs
  nck2      nck.c (SHAKE=10 is its default)
  nck_lite  nck_lite.c
  casa      casa.c
  casat.py  casat.py (python-sat 1.9.dev17, CaDiCaL 1.5.3)
Starting arrays paley_t_k.txt were written in R from CAs::paleyCA(t, k)
(CAs 0.24.4), 0-based, one row per line (README.md).

"Repeated" below means the command was run again on 2026-10-27 after the
array was stored, and gave the stored file byte for byte. The row-elimination
runs have a time limit, so the number of iterations they reach depends on the
machine and its load; those not repeated are listed with the command that
produced the stored file.

A. The command that produced each stored array

Deterministic constructions (no seed):
  python3 weight_arrays.py outdir      CA(10;3,5,2) CA(16;4,5,2) CA(21;4,6,2)
                                       CA(32;5,6,2) CA(42;5,7,2) CA(64;6,7,2)
                                       CA(85;6,8,2)                    repeated (all 7)
  R: A <- CAs::ckrsCA(5, 14, 2); A[A[, 1] == 0, -1]
                                       CA(32;4,13,2)                   repeated

SAT (CaDiCaL is deterministic for a given formula):
  python3 casat.py 11 2 5 3 sat_11_2_5_3.txt cadical153 240        CA(11;2,5,3)   repeated
  python3 casat.py 12 2 7 3 sat_12_2_7_3.txt cadical153 240        CA(12;2,7,3)   repeated
  python3 casat.py 13 2 9 3 sat_13_2_9_3.txt cadical153 240        CA(13;2,9,3)   repeated
  python3 casat.py 14 2 10 3 sat_14_2_10_3.txt cadical153 240      CA(14;2,10,3)  repeated
  python3 casat.py 17 3 16 2 sat_17_3_16_2.txt cadical153 1200     CA(17;3,16,2)  repeated

Simulated annealing (seed, then time limit in seconds):
  ./casa 15 3 12 2 1 60 1.0 0.999 out_15_3_12_2.txt               CA(15;3,12,2)  repeated
  ./casa 16 3 14 2 7 60 1.0 0.999 out_16_3_14_2.txt               CA(16;3,14,2)  repeated

Row elimination from a Paley array (the output file is prefix_N.txt):

  SHAKE=10 ./nck2 160 5 80 2 paley_5_80.txt nck2_5_80 61 1500 80  CA(159;5,80,2)  repeated
  ./nck_lite 226 5 114 paley_5_114.txt lite_5_114 1 1500          CA(225;5,114,2)
  ./nck_lite 252 5 128 paley_5_128.txt lite_5_128 1 1500          CA(251;5,128,2)
