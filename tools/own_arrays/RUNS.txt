Runs behind the arrays of this folder: the 24 of 2026-10-27 (sections A and B) and the
40 of 2026-10-28 (section C)

The runs of sections A and B were made in a Linux x86_64 cloud workspace on
2026-10-27, with the scripts of this folder (compiled with gcc -O2). File names
are those of the working folder; the stored arrays are in ../../table/arrays/ under
CA_N_t_k_v_<first 8 hex digits of the sha256>.txt.

Programs named in the commands:
  nck       nck_early.c, the first version of nck.c (used for the runs
            without SHAKE=); nck.c replaced its enumeration code and added
            the SHAKE random walk, so the two do not give the same runs
  nck2      nck.c (SHAKE=10 is its default)
  nck_lite  nck_lite.c
  casa      casa.c
  casat.py  casat.py (python-sat 1.9.dev17, CaDiCaL 1.5.3)
Starting arrays paley_t_k.txt were written in R from CAs::paleyCA(t, k)
(CAs 0.24.4), 0-based, one row per line (README.md).

"Repeated" below means the command was run again on 2026-10-27 after the
array was stored, and gave the stored file byte for byte. The row-elimination
runs have a time limit, so the number of iterations they reach depends on the
machine and its load; those not repeated are listed with the command that
produced the stored file.

C. The 42 arrays added on 2026-10-28 and 2026-10-29

the table's best size was an array of Torres-Jimenez's group: in the Linux x86_64 cloud
workspace (2 shared cores, every job under nice -n 10) and in a batch on the
maintainer's Apple Silicon MacBook Pro (14 to 15 jobs at a time). Each array below is
the smallest one built at its point with at most his number of rows. No array of
Torres-Jimenez's group was read by any of these runs; the inputs are named below.
