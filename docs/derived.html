Sizes that follow by published constructions

Each line is a size that follows from the counted table (cited and verified entries) by a published construction, and is smaller than the counted value at that point. These are computed sizes, not arrays in hand; the counted table does not include them. The list is recomputed from scratch on every change by tools/derive_table.py and checked line by line, independently of that program, by tools/consistency.py. Every ingredient is written CAN(t,k,v)=N, the value of the lookup (counted or derived) at that point, so each line can be followed back to table entries. Stair-step as in the table: a line (t, v, k, N) gives N for up to k columns. 1082 lines, 2026-11-13.

Past the baseline's column range (k = 20,000 at strength 2, 10,000 above), the table holds only arrays added to it, so the same constructions are also evaluated at a fixed ladder of widths up to k = 100,000 (531 lines). Where the table has no entry that wide, the counted column reads none: the line is the smallest size these constructions give from the table, a yardstick for any array added there, not a survey of the literature.
